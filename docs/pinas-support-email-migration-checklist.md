# Pinas Rewards support-email migration checklist

- [ ] Choose a mailbox controlled by the operating organization.
- [ ] Enable multi-factor authentication and recovery ownership.
- [ ] Add at least two authorized administrators.
- [ ] Configure the production sender name and reply-to address.
- [ ] Configure SPF, DKIM, and DMARC for a custom domain when available.
- [ ] Test delivery to Gmail, Outlook, and Yahoo.
- [ ] Test password reset, signup, agreement, and support replies.
- [ ] Publish the same monitored address in legal documents and the application.
- [ ] Define support hours, escalation coverage, retention, and access review.
- [ ] Remove former sender credentials and confirm no forwarding exposes customer data.

Until a custom mailbox exists, a free organization-controlled mailbox may be used if the address is clearly disclosed and monitored.
